# Student Grade Manager

A console-based application for managing student grades with data persistence.

## Features

- Add new students with unique IDs
- Add grades (0-100) to students
- Calculate and display averages
- Letter grade conversion (A-F)
- Class-wide statistics
- Auto-save/load data to/from files
- Student search and details view

## Technologies

- **Java**: OOP, Collections, Serialization
- **Python**: OOP, JSON, File I/O

## Data Persistence

- Java: Serialization (.ser file)
- Python: JSON (.json file)

## Key Concepts Demonstrated

- Object-Oriented Programming (OOP)
- Collections (HashMap, ArrayList)
- Exception Handling
- File I/O Operations
- User Interface Design
- Data Validation
